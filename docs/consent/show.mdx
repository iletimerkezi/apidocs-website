# JSON Post API
SMS gönderilmesini istemediğiniz bir cep telefonu numarasını, HTTP protokolünün POST metodunu kullanarak, JSON formatında ileterek engellenmiş numara listenize eklemek isterseniz, aşağıdaki yönergeleri takip edebilirsiniz.

## İstek yapılacak adres

<RequestURL type="POST" url="https://api.iletimerkezi.com/v1/consent/show/json" />

## İstek İçeriği (Body)

```json
{
  "request": {
    "authentication": {
      "key": "",
      "hash": ""
    },
    "consent": {
      "brandCode": "696422",
      "type": "MESAJ",
      "recipient": "+90505xxxxxxx veya test@emarka.com.tr",
      "recipientType": "BIREYSEL"
    }
  }
}
```

### Tanımlar

Sunucuya yapılacak olan istek <Badge>request</Badge> etiketi ile sarmalanmalıdır. Bu etiketin alt etiketlerinin tanımları aşağıdaki gibidir:

<AccessDescription />

#### consent
Sorgulanacak izin bilgilerini içeren etiket.

+ **brandCode:** İzin bilgileri sorgulanacak markanın kodu.
+ **type:** İzin türü. <Badge>MESAJ</Badge>, <Badge>EPOSTA</Badge> veya <Badge>ARAMA</Badge> değerlerini alabilir.
+ **recipient:** İzin bilgisi sorgulanacak cep telefonu numarası veya e-posta adresi.
+ **recipientType:** İzin bilgisi sorgulanacak liste türü. <Badge>BIREYSEL</Badge> veya <Badge>TACIR</Badge> değerlerini alabilir.

## Sunucu yanıtı

```json
{
  "response": {
    "status": {
      "code": 200,
      "message": "İşlem başarılı"
    },
    "consent": {
      "brandCode": 696422,
      "recipient": "+90505xxxxxxx veya test@emarka.com.tr",
      "recipientType": "BIREYSEL",
      "type": "MESAJ",
      "status": "ONAY",
      "source": "HS_WEB",
      "consentDate": "2025-12-10 00:00:00"
    }
  }
}
```

### Tanımlar

Sunucudan gelen yanıt her zaman <Badge>response</Badge> etiketi ile sarmalanmıştır. Bu etiketin alt etiketlerinin tanımı aşağıdaki gibidir:

<ResponseStatus />

#### consent
Sorgulanacak izin bilgilerini içeren etiket.

+ **brandCode:** İzin bilgileri gösterilen markanın kodu.
+ **type:** İzin türü. <Badge>MESAJ</Badge>, <Badge>EPOSTA</Badge> veya <Badge>ARAMA</Badge> değerlerinden biri olabilir.
+ **recipient:** İzin bilgisi sorgulanan cep telefonu numarası veya e-posta adresi.
+ **recipientType:** İzin bilgisi sorgulanan liste türü. <Badge>BIREYSEL</Badge> veya <Badge>TACIR</Badge>
+ **status:** İzin durumu. <Badge>ONAY</Badge> veya <Badge>RET</Badge> değerlerini alabilir.
+ **source:** İzin bilgisinin alındığı kaynak. (Örneğin: HS_EORTAM, HS_FIZIKSEL_ORTAM, vs.)
+ **consentDate:** İzin veya ret işleminin gerçekleştiği tarih ve saat bilgisi. Format: YYYY-AA-GG SS:DD:DD
