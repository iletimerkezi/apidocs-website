# JSON Post API
SMS gönderilmesini istemediğiniz bir cep telefonu numarasını, HTTP protokolünün POST metodunu kullanarak, JSON formatında ileterek engellenmiş numara listenize eklemek isterseniz, aşağıdaki yönergeleri takip edebilirsiniz.

## İstek yapılacak adres

<RequestURL type="POST" url="https://api.iletimerkezi.com/v1/consent/create/json" />

## İstek İçeriği (Body)

```json
{
  "request": {
    "authentication": {
      "key": "",
      "hash": ""
    },
    "consent": {
      "brandCode": 696422,
      "list": [
        {
          "recipient": "+90505xxxxxxx veya test@emarka.com.tr",
          "recipientType": "BIREYSEL",
          "source": "HS_EORTAM",
          "status": "ONAY",
          "type": "MESAJ",
          "consentDate": "2026-01-07 23:50:00"
        }
      ]
    }
  }
}
```

### Tanımlar

Sunucuya yapılacak olan istek <Badge>request</Badge> etiketi ile sarmalanmalıdır. Bu etiketin alt etiketlerinin tanımları aşağıdaki gibidir:

#### consent
İYS'ye aktarılacak izin bilgilerini içeren etiket.

+ **brandCode:** İzin bilgileri iletilecek markanın kodu.
+ **list:** İzin bilgilerini içeren etiket. <Badge>list</Badge> etiketi içerisinde birden fazla izin bilgisi gönderilebilir.

	#### list
		+ **recipient:** İzin bilgisi iletilecek cep telefonu numarası veya e-posta adresi.
		+ **recipientType:** İzin bilgisi iletilecek kişinin türü. <Badge>BIREYSEL</Badge> veya <Badge>TACIR</Badge> değerlerini alabilir.
		+ **source:** İzin bilgisinin alındığı kaynak. (Örneğin: HS_EORTAM, HS_FIZIKSEL_ORTAM, vs.)

## Sunucu yanıtı

```json
{
  "response": {
    "status": {
      "code": 200,
      "message": "İşlem başarılı"
    }
  }
}
```
